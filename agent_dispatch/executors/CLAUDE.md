# Адаптеры исполнителей

- omp в режиме run прерывает сессию при отклонённом запросе разрешения; адаптер сообщает `failed` с `permission rejected: ...` вместо молчаливого `partial`.
- omp, в котором модель не ответила ни разу (нет `text`, `toolCall`, `stopReason`; без изменений и без события ошибки), даёт `failed` с `omp.NO_RESPONSE` вместо `partial`: так omp молча выходит, когда запрос к модели не вернулся. `health.classify_failure` считает строку с начала `network`, и вся группа лимита остывает.
