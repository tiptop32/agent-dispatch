# Платная разметка точности fail ревью

Часть B плана 20261115-review-precision.md, отложена 2026-11-15. Ручная разметка
12 fail x5-large (3 оправданы) уже привела к снятию `review_by` у sol.

Предусловия: в `review_stages[i].input_patch` накопились сохранённые патчи (задача 2 плана),
по ревьюеру N ≥ 50. Требования из ревью плана: один судья (local Claude) для всех
ревьюеров, перед запуском судья проверяется на 12 ручных метках; выборка отбрасывает
линии под периметром (`harness._lineage_perimeter`, тест обязателен); единица разметки
одна, замечание или вердикт, выбрать заранее; WARN только если верхняя граница 95% CI
precision ниже 0.7; детерминированный парсер меток, неразборчивый ответ отбрасывается.
