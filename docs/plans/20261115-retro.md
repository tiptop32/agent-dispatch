# Дешёвый retro (задача 3 из 20261115-sadensmol-adoption.md)

## Почему

Каждая поправка пользователя («я же говорил», «не то», «переделай») должна превращаться
в правило, чтобы та же поправка больше не понадобилась. Транскрипты Claude за неделю
весят 238 MB (99 файлов), читать их целиком дорого. Живые сессии и сообщения человека
дают 35 сессий, 261 сообщение и около 54k токенов вместе с хвостом ответа агента
(замер 2026-11-15). Grep по ключевым словам не годится: почти все 26 совпадений из
`# Task`-промптов ложные, а настоящая поправка без ключевого слова пропущена.

## Метрика

Число подтверждённых поправок в неделю, тренд вниз. Цена прогона: токены Claude плюс
$ исполнителя. Доля инцидентов, у которых цитата не нашлась (качество извлечения).

## Поток

1. `extract.py` (детерминированно): сессии `~/.claude/projects/*/*.jsonl` за окно;
   выбрасываются dispatched (первое сообщение человека начинается с `# Task`),
   `isMeta`, `<…>`-обёртки, «Orca restarted», продолжения после compaction. Для каждого
   сообщения: `session`, `turn`, текст и последние 600 символов ответа агента перед ним.
   Добавляются записи журнала решений с вердиктом `change|revert` (задача 1). Секреты
   маскируются теми же правилами, что в `agent_dispatch/dispatch/redact.py`.
   Выход: `/tmp/retro/<неделя>/week.jsonl`.
2. LLM: `dispatch` (роутер, `kind: review`, read-only, capability strong) с файлом из
   шага 1. Явный `dispatch_to sol` не используется: в сессиях бывают данные X5, и
   автоматический периметр должен иметь возможность увести задачу на x5-исполнителя.
   Линзы: требования, переделка, лишний скоуп, повторная поправка. Выход: JSON
   инцидентов `{lens, session, turn, quote, cause, owner_hint}`.
3. `verify.py`: цитата обязана дословно встречаться в сообщении `session:turn`, иначе
   инцидент выбрасывается и учитывается в метрике.
4. Кластеризация дублей по `owner_hint` + похожести цитат (детерминированно, без LLM).
5. Claude в сессии retro: по каждому кластеру предлагает владельца (скилл, CLAUDE.md,
   хук, конфиг) и минимальную правку. Ничего не применяется без одобрения пользователя.
6. Отчёт: таблица «проблема / причина / что поменяли / что делать в следующий раз» +
   секция productivity из `evals.replay` (`review_precision`, задача 2).
   Строка в `~/.local/state/retro/log.jsonl`.
