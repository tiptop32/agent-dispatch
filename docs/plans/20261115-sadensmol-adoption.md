# Что берём из sadensmol.com/skills

Источник: https://sadensmol.com/skills/ (прочитано 2026-11-15).
Ограничение: подписки мелкие. Качество получаем детерминированным кодом
(replay, verify, grep), а не числом агентов.

Не берём: 6 параллельных ревьюеров на задачу, Opus xhigh-планировщик по
умолчанию, pair mode (писатель и ревьюер одновременно), retro на 11 линз,
где LLM читает транскрипты целиком.

## Задачи

Порядок учитывает зависимости. Отдельный план по каждой задаче пишется
перед её выполнением.

| # | Задача | Где | Метрика результата | Зависит от | Объём |

## Решения брейншторма

- Журнал пишут Claude и omp, хранится централизованно в JSONL.
- Ревью: сейчас детерминированная стабильность fail; платная разметка отложена (один судья Claude, фильтр периметра).
- Журнал: по prod-линии в файл пишется только `kind`, текст `(prod)`.
- Retro читает все сообщения человека (около 54k токенов в неделю), а не результаты grep;
  LLM-шаг идёт через роутер диспатчера.
- `/task`: источники Kaiten и свободный текст.
